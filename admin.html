관리자 키

GitHub에서 만든 관리 키를 넣어 주세요. 이 기기에만 저장됩니다.

  1. github.com 로그인 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → field-map
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만든 키를 복사해서 위 칸에 붙여 넣기
